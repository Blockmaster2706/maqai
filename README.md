# Maqai

Maqai is a tool to help installing Rooting tools for the Meta Quest series of Devices. At the core it aims to allow users to follow a series of easy instructions to have a semi-automatic installer for the Singularity Rooting framework and some of the Addons available for it.

Maqai is available as a Windows Installer, a macOS App Bundle or a Linux AppImage. All of these can be found in the Releases folder. Note that Maqai has the ability to update itself automatically when it finds a new release.

### AI Notice
Parts of Maqai were written using the help of LLMs. I do however guarantee that I read over the output of such LLMs, decided on the important architecture of the app myself, and made sure that it works well.
